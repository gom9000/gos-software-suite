# Software Suite
Personal hub of software-related repositories.<br/>

This suite is my personal hobby workbench. It documents my explorations outside of daily work. Here, logic takes shape through code, or maybe remains sawdust of bits.

>**[TrayTree](https://github.com/gom9000/traytree)**<br/>
>**Type**: Windows Utility | **Status**: Completed
>
>A Windows system-tray utility designed to provide quick access to directory links through a tree-like menu. It allows managing file system navigation directly from the tray area.

>**[TrayServiceMonitor](https://github.com/gom9000/TrayServiceMonitor)**<br/>
>**Type**: Windows Utility | **Status**: Completed
>
>A lightweight Windows service monitor that lives in the system tray. It provides real-time status updates and control over local Windows services.

>**[YaTris](https://github.com/gom9000/yatris)**<br/>
>**Type**: Windows Funny | **Status**: Completed
>
>*"Yet Another Tris"* - a simple C++ implementation of the classic Tic-Tac-Toe game for the Windows environment.


>**[JacORB SSL Extension](https://github.com/gom9000/JacORB-SSL-ExtLib)**<br/>
>**Type**: Module | **Status**: Completed
>
>An extension library for JacORB 2.2.4 that provides custom Socket and ServerSocket factories. It enables port range management on SSL sockets for CORBA-based systems.

>**[Empire Java Library](https://github.com/gom9000/empire)**<br/>
>**Type**: Notes | **Status**: Completed (*Deprecated*)
>
>A collection of general-purpose Java utility classes for tag hierarchies, logging, configuration, and filesystem management for *old style* Web Applications. Its motto: *"Empire, state: building!"*.

>**[MicroLib - x86 DOS C/BIOS Utility Libraries](https://github.com/gom9000/microlib-mul)**<br/>
>**Type**: Notes | **Status**: Completed (*Deprecated*)
>
>A set of C libraries for DOS environments. It includes the [MUL (Micro Utilities Library)](https://github.com/gom9000/microlib-mul), the [MGL (Micro Graphic Library)](https://github.com/gom9000/microlib-mgl) for PC BIOS-based graphics and the [Micro Mouse Library](https://github.com/gom9000/microlib-mouse) for low-level mouse handling.
